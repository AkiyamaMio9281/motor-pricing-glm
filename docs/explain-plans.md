# Execution plans

Generated by `scripts/explain_plans.py` against the loaded mart. Do not edit by hand; re-run the script.

Each variant ran 5 times in its own rolled-back transaction; times are medians. The *without index* variant drops the index inside the transaction, which Postgres allows because `DROP INDEX` is transactional, so both variants are measured from the same final schema. Postgres 16, stock settings, Docker on Windows 11.

## Summary

| Query | Index | Without | With | Change |
